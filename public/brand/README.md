# Brand assets

Place SVG files here once received from the designer:

- `wordmark.svg`  — full "CADENZIA" lockup
- `mark.svg`      — symbol only (converging fan / mesh mark)

Currently only PNG versions exist (`cadenzia_logo.png`, `cadenzia_simbolo.png`).
Do not use PNGs in the app UI — they render poorly at small sizes and can't be
styled with CSS. Follow up with the designer for vector exports.
